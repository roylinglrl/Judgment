本院认为，著作权法保护的作品，是指文学、艺术和科
学领域内具有独创性并能以一定形式表现的智力成果。原告绘制的西格莉德·贝丝人物形象，体现了其具有独创性的
表达，属于美术作品。被告称该人物形象与《重返未来 1999》
中的张之之相似，根据比对，两人物形象存在显著区别，其
中相似的元素不足以否认案涉作品的独创性。原告制作的
皮肤，其美术设计元素体现了原告对于人物发型、服饰具
有审美意义的选择，构成美术作品。
《中华人民共和国著作权法》第十一条规定，著作权属
于作者，本法另有规定的除外；如无相反证明，在作品上署
名的公民、法人或者其他组织为作者。最高人民法院《关于
6
审理著作权民事纠纷案件适用法律若干问题的解释》第七条
规定，当事人提供的涉及著作权的底稿、原件、合法出版物、
著作权登记证书、认证机构出具的证明、取得权利的合同等，
可以作为证据，如无相反证明，在作品或者制品上署名的自
然人、法人或者其他组织视为著作权或者著作权有关权益的
权利人。本案中，原告提交的证据足以认定其是涉案美术
作品的著作权人。
原告在本案中主张被告存在以下六个侵权行为：1．盗
用作品于制作视频；2、在 QQ 群内传播原告作品；3、使
用原告作品作为群头像；4、发布不实信息并造谣抹黑，
截取 QQ 群片面聊天记录，传播不实信息；5、将原告享有
著作权的作品使用人工智能工具二次生成修改或演绎，并在
被告管理的 QQ 群（236887187）内公开传播；6、恶意举报
曝光视频。
对于原告主张的上述行为，其中第四、第六项并非著
作权法涉及内容，在本案中不予处理。就其余行为分析如下：
第一项行为，根据被告提供的证据，在其制作并发布视
频之前，原告在 QQ 群内上传其制作的皮肤文件并发送内
容“路哥路哥”“你有我的皮肤吗”“没有的话你就拿去用吧”，
因此前被告已与网名为“路哥”的被告发生口角冲突，知晓
被告的存在，原告在 QQ 群中除呼叫“路哥”，无其他特定
指向，在此种情况下，极易导致误解，本院认为被告使用该
皮肤制作视频系基于原告的前序邀请行为，无论该邀请行
为是出于善意或恶意。根据著作权法的规定，使用他人作品
应当与著作权人订立许可使用合同，许可使用合同中著作权
人未明确许可的权利，未经著作权人许可，另一方当事人不
得行使。原告在 QQ 群内发送的上述内容并未明确许可使
7
用的权利种类、地域范围等信息，且双方未签订许可使用合
同，因此，原告的上述行为不应视为对被告的许可授权。
被告未经许可使用原告制作的皮肤，侵害了其著作权。但
因被告该使用行为系基于原告的前序邀请行为，故被告仅
需承担停止侵权的责任，无需就该行为承担赔偿责任。
第二项和第五项行为，对于原告提供的 QQ 聊天记录，
被告认可昵称“路哥”、“B 站：不走寻常路的路哥 1 号【地
图＋整合包】”、“惜念”账号所发内容为其本人发送，包括两
张人物形象原图，以及多张合成处理的图片。被告未经原告的授权，在 QQ 群中发送原告享有著作权的美术作品，
侵害了原告对于该作品的信息网络传播权。作者有保护作
品不受歪曲、篡改的权利，其有权保护其作品不被他人丑化，
不被他人作违背其思想的删除、增添或者其他损害性的变动。
被告在 QQ 群内发送的部分图片，系使用图片编辑软件或人
工智能对原告作品进行修改演绎而成，与原作品相比，结
合部分文字内容，具有贬损含义，侵害了原告的保护作品
完整权。
第三项行为，根据原告提交的证据，QQ 群“圣人蓝
若绫的圣徒交流群”“蓝若绫小画师交流群”使用头像与原告创作的人物形象构成实质相似，但根据现有证据，无法
证明上述 QQ 群由被告创建，故对于该项行为不予确认。
综上，被告在 QQ 群中上传原告享有著作权的作品、
使用图片编辑软件、人工智能对案涉作品编辑并上传网络的
行为，侵害了原告的信息网络传播权、保护作品完整权，
应承担停止侵权、消除影响、赔礼道歉、赔偿损失的民事责
任。
